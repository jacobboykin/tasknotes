# TaskNotes

TaskNotes organizes actionable work in an Obsidian vault while keeping Markdown notes as the durable source of truth.

## Language

**Task**:
A concrete action that can be completed.
_Avoid_: Todo item, reminder

**Project**:
A finite outcome that requires multiple Tasks and can belong to an Area or contribute to a Goal.
_Avoid_: Folder, category

**Area**:
An ongoing sphere of responsibility that does not have a completion point.
_Avoid_: Category, label

**Goal**:
A measurable desired outcome that one or more Projects can advance.
_Avoid_: Project, milestone

**Relationship**:
An explicit, typed association stored on its source note, such as a Task belonging to a Project or a Project belonging to an Area.
_Avoid_: Backlink, mention

**Mention**:
An ordinary link to a note that carries no TaskNotes relationship meaning.
_Avoid_: Relationship
